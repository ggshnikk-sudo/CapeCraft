# capecraft-lsp 1.1.5

Функциональность та же, что у 1.1.4. Исправлена версия, которую сервер
сообщает клиенту, и сборка сервера поставлена под CI.

## Что исправлено

**`serverInfo.version` больше не врёт.** В jar'е 1.1.4 манифест содержал
`Implementation-Version: 1.1.4`, а `LspServer.version` остался `1.1.3` — то есть
клиент видел в информации о сервере прошлую версию. Теперь обе версии совпадают
с тегом: `1.1.5`. Расхождение не ломалось на тестах, потому что версия в
`serverInfo` ни на что не влияет; ловить его теперь будет CI.

## Что добавлено в репозитории

**Job `lsp` в `.github/workflows/ci.yml`.** Раньше сервер собирался только в
`lsp-release.yml` по тегу `lsp-v*`, то есть ошибка в нём обнаруживалась уже при
выпуске релиза. Теперь на каждый push и pull request идут
`./gradlew test --tests 'dev.ggtv.capecraft.lsp.*'` и `./gradlew lspJar`,
а собранный `capecraft-lsp.jar` доступен как артефакт прогона.

## Проверено

- 80 тестов сервера (`dev.ggtv.capecraft.lsp.*`) — падений нет;
- `./gradlew lspJar` собирает `artifacts/capecraft-lsp.jar` с
  `Implementation-Version: 1.1.5`;
- `initialize` отдаёт `serverInfo.version = 1.1.5`.

## Установка

Без изменений: скачать `capecraft-lsp.jar` из релиза и указать на него
`CAPECRAFT_LSP_JAR` (Zed) или путь в `cmd` (Neovim). Имя jar'а по-прежнему без
версии — конфиг редактора править не нужно.
